# Site Institucional - Desafio Android 📱

Projeto desenvolvido para consolidar conhecimentos de **Responsividade** e **Design Adaptativo**. O objetivo foi criar uma página que se ajusta perfeitamente desde monitores desktop até telas de smartphones, mantendo a legibilidade e a estética.

## 🚀 Tecnologias Utilizadas
- **HTML5:** Estruturação semântica da página.
- **CSS3:** Uso de variáveis internas para facilitar a manutenção de cores.
- **Media Queries:** Implementação de pontos de quebra para layout responsivo.
- **Design:** Conceitos de UI/UX baseados no guia de estilo do projeto.

## 🧠 O que eu aprendi
Neste projeto, foquei em resolver desafios comuns de Front-End:
1. **Hierarquia Visual:** Organização de títulos e textos para guiar o olhar do usuário.
2. **Flexibilidade:** Uso de unidades relativas para que o layout não "quebre" em telas menores.
3. **Estilização Avançada:** Criação de componentes personalizados (como o rodapé e áreas de destaque) usando seletores CSS.
